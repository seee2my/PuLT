# Пульт LG 32LB530U (ИК, Android)

Приложение для Redmi Note 10 Pro: управляет телевизором LG 32LB530U через встроенный ИК-порт.
Кнопки: вкл/выкл, вход, без звука, громкость ±, каналы ±, меню, Q.Меню, стрелки + OK, назад, выход, цифры 0–9.
Удержание кнопок громкости, каналов и стрелок повторяет команду.

## Как получить APK

### Вариант 1: GitHub Actions (без установки чего-либо)
1. Создайте пустой репозиторий на github.com и загрузите в него все файлы этой папки (включая скрытую `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
3. Через 3–5 минут скачайте `LGRemote-apk` из раздела Artifacts, распакуйте — внутри `app-debug.apk`.

### Вариант 2: Android Studio
File → Open → выберите эту папку → дождитесь синхронизации → Build → Build APK(s).
Файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка
Скопируйте `app-debug.apk` на телефон, откройте и разрешите установку из этого источника.

## Если телевизор не реагирует
- ИК-порт Redmi находится на верхнем торце: направляйте его на телевизор, расстояние до 5 м.
- Если команда не срабатывает, измените `CARRIER_HZ` или коды в `MainActivity.java`.
